# CADLite 🚀

> Industrial CAD to Web 3D lightweight pipeline

<!-- [![npm version](https://img.shields.io/npm/v/cadlite)](https://www.npmjs.com/package/cadlite) -->

## ✨ 功能

- 🔄 **输入**：STEP
- 📦 **输出**：离散化数据 + 结构树
- ⚡ **智能减面**：基于 meshoptimizer 的高性能网格简化
- 🧩 **实例化去重**：自动检测并优化重复零件
- 💾 **内存友好**：流式处理，支持大型工业装配体
